# Setup — zero install

You only need two things: a GitHub account and a web browser.

---

## Step 1 — Sign in to GitHub

Go to https://github.com/login and sign in.

If you don't have an account, go to https://github.com/signup. Use your email and create one. It's free.

---

## Step 2 — Open this repo

Go to:

https://github.com/sicxz/open-code-test

---

## Step 3 — Open the web editor

Press the **`.`** (period / dot) key on your keyboard.

A VS Code-like editor will open in your browser. This is called **github.dev**. Nothing to install — it's just a webpage.

---

## Step 4 — Look around

On the left sidebar you'll see the file list:

- `command-center.html` — the page itself
- `README.md` — this file (we'll update it later)
- `Important infographics/` — images used on the page
- `STEP 3 __ Research Map + Information Interactions/` — more images

Click any file to open it.

---

## Step 5 — Make a change

Click `command-center.html` in the file list to open it.

Scroll to about line 45 (look at the line numbers on the left). You'll see:

```html
<span class="badge badge--green">Research Phase</span>
```

Change `Research Phase` to something else, like `Build Phase` or `In Progress`.

---

## Step 6 — Save your change

Click the **branch icon** on the left sidebar (it looks like a fork in a road — that's the Source Control panel, 3rd icon from the top).

You'll see your changed file listed under **Changes**.

**Type a message** in the text box that says "Message" — something like `update status badge`.

Click the blue **Commit & Push** button.

Done. Your change is saved to the repo.

---

## Step 7 — Turn the page into a live website

Go back to your repo on GitHub (close the editor tab or navigate back to https://github.com/sicxz/open-code-test).

Click the **Settings** tab at the top.

In the left sidebar, click **Pages**.

Under **Branch**, select `main` and keep the folder as `/ (root)`.

Click **Save**.

Now scroll up — you'll see a blue banner that says "Your site is live at" with a URL. That URL is your published page.

Wait 1–2 minutes. Then open that URL in a new tab.

---

## Step 8 — Make more changes, repeat

Want to change something else?

1. Go to https://github.com/sicxz/open-code-test
2. Press `.` (dot) — web editor opens
3. Edit any file
4. Click the branch icon → type a message → **Commit & Push**
5. The live page updates automatically after a minute

That's it. No git. No terminal. No app installs.


---

## What is GitHub doing?

- **Git** tracks every version of your files. When you click Commit & Push, it saves a snapshot.
- **GitHub** stores your project online so others can see it.
- **GitHub Pages** turns your HTML files into a website anyone can visit.

You don't need to understand how git works yet. Just know that every Commit & Push saves your work and updates the live page.
